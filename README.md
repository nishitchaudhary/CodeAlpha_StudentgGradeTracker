# 📊 CodeAlpha: Student Grade Tracker

Welcome to my repository for the **Student Grade Tracker**! This project was developed as part of my Java Programming Internship with CodeAlpha. It demonstrates foundational object-oriented programming (OOP) principles, dynamic data structures, and Graphical User Interface (GUI) design.

## 🚀 Project Overview
This project is a GUI-based Java application designed to efficiently manage and analyze student performance data. Utilizing Java Collections, the system dynamically stores grades and computes key academic metrics—such as the class average, highest score, and lowest score—using a streamlined, single-pass algorithmic approach. It includes robust input validation via Swing dialogs to ensure seamless execution and data integrity.

## 🛠️ Technologies Used
* **Language:** Java
* **GUI Framework:** Java Swing & AWT (`JOptionPane`, `JTextArea`, `JFrame`)
* **Concepts:** Object-Oriented Programming (OOP), ArrayLists, Event-Driven Programming
* **IDE/Environment:** Eclipse / VS Code

## ✨ Key Features
* Dynamic data storage using `ArrayList`.
* Interactive and intuitive Graphical User Interface (GUI).
* Robust user input validation with error-handling pop-ups.
* Highly efficient $O(n)$ single-pass algorithm for calculating highest, lowest, and average grades.
